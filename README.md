# Яндекс.Почта (Элементы Яндекса) — порт на Manifest V3

Порт расширения 8.22.3 (ID `lonndeeklpobbkjaacljjjkddafbbbfa`) для браузеров на Chromium, где Manifest V2 больше не поддерживается.

## Установка в Яндекс Браузере
1. Откройте `browser://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку.
4. Не удаляйте и не переносите папку: браузер загружает расширение прямо из неё.

## Как устроено
- `mv3/sw.js` — service worker. Создаёт offscreen-документ и выполняет за него вызовы `chrome.*`.
- `offscreen.html` — запускает прежний фоновый код (`background/backend.js`, `slice/slice-backend.min.js`) без изменений.
- `mv3/bg-compat.js` — подмена `chrome.*` внутри offscreen-документа (вызовы идут через порт в service worker).
- `mv3/page-compat.js` — для popup и страницы настроек: возвращает `getBackgroundPage` (окно offscreen-документа) и `extension.getURL`.

## Отличия от оригинала
- Режим «split» для инкогнито убран (в MV3 с offscreen-документом он недоступен).
- Блокирующий `webRequest` убран: его использовал только внутренний модуль отслеживания XHR.
- Автообновление (`update_url`) отключено, чтобы браузер не заменил порт старой MV2-версией.
